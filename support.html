Getting started

What do I need to use GiVo Stream?

An iPhone, iPad, or Apple TV running iOS/iPadOS/tvOS 17 or later, and a playlist from your own content source — either a standard M3U URL or an Xtream Codes login. GiVo Stream does not provide any channels or content itself.

How do I add my playlist?

Open Settings → Playlist Manager → Add Playlist, choose M3U & EPG or Xtream Codes, and paste your details. Guide data (XMLTV/EPG) can be filled automatically for Xtream logins or supplied as a separate URL.

Do I need the GiVo Server app?

Only for DVR features — recording, scheduling, and watching recordings across devices. Playback, the guide, and pause/rewind of live streams work without it. Download GiVo Server for macOS or Windows, install it on a computer that stays on your home network, and pair from the app.

Pairing & the DVR server

My server doesn't show up under Available Servers

Discovery uses your local network (mDNS/Bonjour), so the computer and your Apple device must be on the same network and VLAN.

  • Windows: make sure the firewall allowed givo-server.exe — the installer sets this up, so if you use the portable zip instead, allow it when Windows asks (Private networks).
  • Any platform: you can always connect directly — choose Add Server Manually, enter the computer's IP address and port (8088 by default), and pair with the code as usual. The server's address is shown in its menu under “URL”.

Where do I find the pairing code?

Click the GiVo icon in the Mac menu bar or Windows system tray — the current pairing code is shown right in the menu and can be clicked to copy. A random code is generated each launch, or you can set your own 6-digit code in the server's Settings.

Where are my recordings stored?

On the computer running GiVo Server, in the GiVo Recordings folder inside your user folder by default. You can change the location in the server's Settings. Recordings never leave your hardware.

Windows says the app is unrecognized / SmartScreen warning

The Windows installer is currently unsigned, so SmartScreen shows a one-time warning for new downloads. Click “More info” → “Run anyway”. The macOS app is notarized by Apple and opens normally.

Playback

A stream says “temporarily unavailable” or takes a while to load

That message comes from your content provider — it usually means the provider is limiting simultaneous connections on your account. GiVo Stream retries automatically and shows the status while it does. If it happens constantly, check how many devices are using the same login at once and your plan's connection limit.

Pause and rewind — how far back can I go?

From the moment you start a stream, GiVo Stream keeps a rolling timeshift buffer on-device, so you can pause and scrub back within the current session. For permanent copies, record to your GiVo Server.

Features & settings

Does GiVo Stream sync between my devices?

Yes. Turn on sync in Settings → Sync & Data and your playlists, favorites, and settings follow you across iPhone, iPad, and Apple TV — through your own private iCloud, never our servers. You can choose exactly what syncs.

How do I set a reminder for a show?

Open the program in the guide and choose Remind. You'll get a notification just before it starts. Reminders pair nicely with scheduled recordings — set both and the show is waiting for you either way.

How do parental controls work?

Two layers: lock categories behind a PIN so they need a code to open, or hide channels entirely so they never appear in the lineup — perfect for keeping the guide family-friendly on shared devices like the living-room Apple TV.

Can I change how far the skip buttons jump?

Yes — Settings → Playback lets you pick 10, 15, 30, or 60-second jumps for rewind and fast-forward. The same intervals apply to the Lock Screen and Control Center buttons.

Audio tracks and subtitles?

Streams with multiple audio languages or subtitle tracks expose them in the player's playback menu, and you can set a default audio language in Settings so the right track is chosen automatically.

How often do playlists and guide data refresh?

Your choice: on app launch, every 1–24 hours, or manual-only — set separately for playlists and guide data in Settings → Playlist & EPG Refresh. There's always a Refresh Now button when you want it immediately. Guide data can be kept for up to 7 days ahead.

Picture in Picture and background audio?

Both. On iPhone and iPad you can pop playback into a floating window while you use other apps, or let the audio continue in the background with full Lock Screen / Control Center controls.

Recording

How do I stop or cancel a recording?

From the DVR tab (or the recording's row in the guide), choose Stop to end an in-progress recording and keep what was captured, or Delete to remove it entirely. Scheduled recordings can be cancelled any time before they start.

What happens if my connection drops mid-recording?

GiVo Server automatically reconnects and repairs the recording, stitching the parts together when it finalizes. If the source never comes back, you keep everything captured up to the drop as a partial recording.
