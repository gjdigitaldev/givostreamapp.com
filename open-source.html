Open Source

GiVo Stream for iPhone, iPad, and Apple TV is built with the open-source components below. Each entry names its license and links to its source; for AetherEngine and its FFmpeg build, the links point at the exact source used in the app, and the exact source of KSPlayer and its FFmpeg build is available on request. The same notices and license texts are in the app under Settings → Privacy & Support → Open-Source Licenses.

KSPlayer

Media playback in GiVo Stream is powered by KSPlayer, copyright its contributors, used under the GNU Lesser General Public License v3.0. GiVo Stream uses a modified version of KSPlayer, linked statically into the app.

Source for the exact builds of KSPlayer and FFmpegKit used in the app, including our modifications, is available on request: support@givostreamapp.com.

  • Upstream project: kingslay/KSPlayer

FFmpeg and the libraries in KSPlayer's build

KSPlayer uses FFmpeg n9.0.2 and the libraries below, built by FFmpegKit and linked statically into the app. This FFmpeg build is configured with the version 3 option and no GPL components, so it is licensed under the GNU Lesser General Public License v3.0 or later. FFmpegKit applies a set of patches to FFmpeg, published in the upstream FFmpegKit project under Plugins/BuildFFmpeg/patch/FFmpeg. GiVo Stream uses a modified version of FFmpegKit (LGPL v3.0): release 9.0.3 rebuilds FFmpegKit 9.0.2 as static libraries, adds a libzvbi patch, and changes the build plugin and package manifest.

Source of the exact build used in the app: available on request. Upstream project: kingslay/FFmpegKit.

FFmpeg and the libraries in AetherEngine's build

AetherEngine uses its own build of the FFmpeg libraries, packaged by FFmpegBuild. They are embedded in the app as dynamic frameworks, so they can be replaced with a modified version as section 6 of the LGPL v2.1 provides. The build enables no GPL or LGPL v3 components. FFmpegBuild applies a small set of local patches to FFmpeg and removes libzvbi's three GPL-2 source files, replacing the two entry points they provided with LGPL stubs; each change is documented in FFmpegBuild's README and published in its build script.

Source of the exact build used in the app: gjdigitaldev/FFmpegBuild, release 3.6.0, revision fda08325455bc12c112b5b82d014b98fa0fee0be (the same release as the upstream superuser404notfound/FFmpegBuild 3.6.0).
